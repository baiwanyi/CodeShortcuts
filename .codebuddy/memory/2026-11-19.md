## 修改内容摘要
- 面板顶部新增 Tabs 切换：提示词 / 系统命令 / 收藏夹；系统命令由原先的底部固定区改为独立分区。顶部分区切换改为 shadcn Tabs 的 `variant="line"` 受控实现，并移除收藏数量徽标，仅保留文字标签与激活下划线。修复 shadcn CLI 生成组件与当前 Radix 版本属性不匹配：`data-active` / `data-horizontal` / `group-data-{horizontal,vertical}` 改用 `data-[state=active]` / `data-[orientation=...]`，激活下划线与内嵌样式生效。在调用处覆盖 TabsTrigger 的焦点边框、ring 与 outline 为无。容量徽章从 PanelHeader 移到 PanelTabs，与三个分区标签并列常驻。PanelHeader 系列四个组件重命名为 PromptHeader 系列（文件、组件、Props 类型与引用同步更新）。
- 新增收藏夹功能：支持新建、编辑、删除网址，点击条目由宿主调用 VS Code 内置简单浏览器（`simpleBrowser.show`）打开。
- 收藏数据存入 globalState 并登记 Settings Sync，与提示词一样支持设置同步；Webview 与宿主双向校验网址，仅允许 http/https 协议。
- 打开网址的方式由 `vscode.env.openExternal`（系统默认浏览器）改为 `simpleBrowser.show`（VS Code 内置浏览器），同步更新协议注释与失败提示文案。
- 修复扩展清单校验错误：`contributes.submenus[].id` 含点号不合法，改为 `baiwanyi-prompt-editor-context`，并同步 `menus` 中的 submenu 引用与菜单键。
- 仓库地址统一改为 `https://github.com/baiwanyi/CodeShortcut.git`（SSH：`git@github.com:baiwanyi/CodeShortcut.git`），同步更新 package.json 的 repository/homepage/bugs 与 README 的徽章、克隆、反馈链接。
- 根据当前代码与功能完整重写 README：新增三分区面板、收藏夹、系统命令与数据限制说明；修正右键动作模式、VSIX 文件名、许可证署名、Node/pnpm 要求、发送链路与 FAQ 中与代码不符之处。
- 标题栏 / 命令面板的「新建」改为通用请求 `requestCreate`：由 Webview 按当前分区分发，提示词分区新建提示词，收藏分区新建收藏，系统命令分区回退提示词。
- 项目品牌统一为 CodeShortcuts：清单 name/displayName/category/视图与配置标题、VSIX 文件名、README 与源码用户可见文案均已更新；命令 ID、配置键、存储键保持不变。GitHub 仓库地址随后也统一为 `https://github.com/baiwanyi/CodeShortcuts.git`。
- 通过 gh 将远端仓库 `baiwanyi/vscode-prompt-shortcut` 重命名为 `baiwanyi/CodeShortcuts`，并把本地 `origin` 更新为 `git@github.com:baiwanyi/CodeShortcuts.git`。
- 全部 11 个命令 ID 由 `baiwanyi.prompt.*` 改为 `codeshortcuts.prompt.*`（含清单声明、菜单引用、命令注册与右键/工具动作定义）。
- 配置键、存储键、视图 ID 与日志标签随后也统一为 `codeshortcuts.prompt.*`；在 activate 中一次性清除旧前缀的 globalState 键（3 个）与用户级配置键（8 个），旧数据不迁移且不可恢复。
- README 副标题最终定为「把常用提示词送达 CodeBuddy，把收藏网址与开发命令收进侧边栏」，明确仅提示词与 CodeBuddy 相关。

- 收藏网址输入改用 InputGroup 固定显示 `https://` 前缀：表单只存主机与路径，粘贴的 http/https 协议自动剥离，提交时拼回完整网址；README 同步说明。
- 收藏图标最终改为用户自选方案：完全移除远程 favicon 请求与 Google CSP 放行，新增 20 个 lucide 图标键与 10 个背景色键（含黑白灰，含白名单守卫与默认值），随 Bookmark / BookmarkDraft 一同持久化；编辑弹窗按 PromptEditorDialog 样式把图标与背景色并排为两列，两者均改为下拉单选（BookmarkIconPicker / BookmarkColorPicker），列表按所选外观渲染。历史数据缺字段时回落默认外观。下拉触发器与菜单项共用同一份图标/色块映射与名称表，白名单校验收敛在选择器内；两个菜单内容区均设 max-h-60 并在超出时滚动。背景色列表按「白、灰、黑、红、橙、黄、绿、青、蓝、紫」排列，白色为默认值，白底时列表图标改用 gray-800 保证对比度。
- 修复第二次清单校验错误：视图容器 ID 与视图 ID 含点号不合法，改为 `codeshortcuts-prompt` / `codeshortcuts-prompt-sidebar` 并同步 `when`、源码常量；子菜单 ID 同步改为 `codeshortcuts-prompt-editor-context`。
- 修复 vsce 打包校验错误：`@types/vscode` 1.146.0 高于 `engines.vscode` ^1.144.0。最终采用升级引擎方案：`engines.vscode` 提升至 ^1.146.0，`@types/vscode` 保持最新版 1.146.0，README 的版本要求同步改为 1.146.0 或更高。重新执行 `pnpm run package` 验证：tsc 类型检查、esbuild、vite 构建、vsce 打包（13 个文件，189.83 KB）与本机安装均通过。
- 修复收藏夹列表内容横向撑开侧边栏：真正根因是 Radix ScrollArea 内容层的内联样式 `display:table; min-width:100%`，表格按内容最大宽度铺开，长网址的 `white-space:nowrap` 把表撑到网址宽度，条目的 `w-full` 与 `truncate` 因此失效、右侧操作按钮被顶出可视区。仅改条目本身无效，须在 ScrollArea 的 Viewport 用 `[&>div]:block! [&>div]:min-w-0! [&>div]:w-full!` 覆盖内容层内联样式，把宽度固定到视口（纵向高度仍按内容测量，不影响滚动）。同时 BookmarkItem 覆盖 `w-fit`/`flex-wrap` 为定宽不换行、BookmarkList 容器与 ScrollArea 补 `min-w-0`。已核对编译产物 CSS 中三条 !important 规则均正确生成，重新打包安装到本机。
- 发布 v0.1.5：原本地 tag v0.1.5 指向旧提交 d0c3d6c，但从未推送远端、GitHub 也无对应 Release；删除该本地 tag 后重跑 `node scripts/release.mjs`，基于当前 HEAD（2b6a1d7，含包名改为 codeshortcuts4vscode 与布局修复）重建附注标签并推送，生成 Release 与附件 codeshortcuts4vscode-0.1.5.vsix。已确认 tag 解引用指向 HEAD、Release 存在且附件完整。
